# 🔑 GUIA SUPER DETALHADO - CRIAR API KEYS

## 📱 **IMPORTANTE: LEIA ANTES DE COMEÇAR**

Você vai criar **2 API Keys**:
1. **Google Gemini** (IA para processar documentos)
2. **Groq** (IA para validar e transcrever áudio)

**Tempo total**: 5-10 minutos
**Custo**: $0 (totalmente gratuito)

---

# 🟦 PARTE 1: CRIAR API KEY DO GOOGLE GEMINI

## **PASSO 1: Abrir o link correto**

**COPIE E COLE ESTE LINK NO SEU NAVEGADOR:**
```
https://aistudio.google.com/app/apikey
```

**OU clique aqui se estiver no celular:**
👉 https://aistudio.google.com/app/apikey

---

## **PASSO 2: Fazer login com Google**

Você vai ver uma tela pedindo login.

**O que fazer:**
1. Digite seu email do Gmail
2. Clique em "Próxima" (ou "Next")
3. Digite sua senha
4. Clique em "Próxima" (ou "Next")

**Se já estiver logado**, pula para o Passo 3.

---

## **PASSO 3: Criar a API Key**

Depois de fazer login, você vai ver uma tela com o título:
**"Get an API key"** ou **"Obter uma chave de API"**

**O que fazer:**

### **Opção A: Se você VÊ um botão azul escrito "Create API key"**
1. Clique no botão azul **"Create API key"**
2. Vai aparecer uma janela perguntando sobre projeto
3. Clique em **"Create API key in new project"** (primeira opção)
4. Aguarde 3-5 segundos
5. **PRONTO!** A chave vai aparecer

### **Opção B: Se você VÊ uma lista de chaves**
1. Procure um botão **"+ Create API key"** (com sinal de +)
2. Clique nele
3. Clique em **"Create API key in new project"**
4. Aguarde 3-5 segundos
5. **PRONTO!** A chave vai aparecer

---

## **PASSO 4: Copiar a chave**

Você vai ver algo assim:
```
AIzaSyD...xxxxx...xxxxx
```

**O que fazer:**
1. Clique no ícone de **copiar** (📋) ao lado da chave
2. OU selecione todo o texto e copie (Ctrl+C ou Cmd+C)
3. **GUARDE BEM ESSA CHAVE!** Você vai precisar dela

**DICA:** Cole em um bloco de notas temporário para não perder.

---

## **PASSO 5: Confirmar que funcionou**

A chave do Gemini sempre começa com:
```
AIzaSy...
```

Se a sua chave começar com `AIzaSy`, está **CORRETO!** ✅

---

# 🟩 PARTE 2: CRIAR API KEY DO GROQ

## **PASSO 1: Abrir o link correto**

**COPIE E COLE ESTE LINK NO SEU NAVEGADOR:**
```
https://console.groq.com/keys
```

**OU clique aqui se estiver no celular:**
👉 https://console.groq.com/keys

---

## **PASSO 2: Criar conta ou fazer login**

Você vai ver uma tela com várias opções de login:

### **OPÇÃO MAIS FÁCIL: Continue with Google** ⭐ (RECOMENDADO)
1. Clique no botão **"Continue with Google"**
2. Escolha sua conta do Gmail
3. Clique em "Permitir" ou "Allow"
4. **PRONTO!** Você está logado

### **OPÇÃO 2: Continue with GitHub**
1. Clique no botão **"Continue with GitHub"**
2. Faça login no GitHub (se pedido)
3. Clique em "Authorize"
4. **PRONTO!** Você está logado

### **OPÇÃO 3: Continue with email**
1. Digite seu email no campo
2. Clique em **"Continue with email"**
3. Vá no seu email e abra a mensagem do Groq
4. Clique no link de confirmação
5. **PRONTO!** Você está logado

**RECOMENDO: Use "Continue with Google" (é mais rápido!)**

---

## **PASSO 3: Aceitar termos (se pedido)**

Se aparecer uma tela pedindo para aceitar termos:
1. Marque a caixinha ☑️
2. Clique em "Accept" ou "Aceitar"

---

## **PASSO 4: Criar a API Key**

Agora você está na página de API Keys.

**O que fazer:**

1. Procure um botão **"Create API Key"** (geralmente no canto superior direito)
2. Clique nele
3. Vai aparecer uma janela pedindo um nome
4. Digite: **"App Rounder"** (ou qualquer nome que quiser)
5. Clique em **"Submit"** ou **"Create"**
6. **PRONTO!** A chave vai aparecer

---

## **PASSO 5: Copiar a chave**

**⚠️ ATENÇÃO: A chave só aparece UMA VEZ!**

Você vai ver algo assim:
```
gsk_xxxxx...xxxxx...xxxxx
```

**O que fazer:**
1. Clique no ícone de **copiar** (📋) ao lado da chave
2. OU selecione todo o texto e copie (Ctrl+C ou Cmd+C)
3. **GUARDE BEM ESSA CHAVE!** Você NÃO vai conseguir ver ela de novo

**DICA:** Cole em um bloco de notas temporário para não perder.

---

## **PASSO 6: Confirmar que funcionou**

A chave do Groq sempre começa com:
```
gsk_...
```

Se a sua chave começar com `gsk_`, está **CORRETO!** ✅

---

Agora que você tem as 2 chaves, vamos colocar no app!

## **PASSO 1: Abrir o App**

**COPIE E COLE ESTE LINK:**
```
https://app-rounder.vercel.app
```

**OU clique aqui:**

1. Clique no segundo campo (escrito "Cole sua API Key do Groq")
2. Cole a chave que começa com `gsk_...`
3. Veja o ✓ verde aparecer

---

## **PASSO 3: Confirmar que salvou**

Se você vê **2 marcas verdes ✓**, está **TUDO CERTO!** 🎉

As chaves foram salvas automaticamente no seu navegador.

**Você NÃO precisa fazer isso de novo!**

# 🆘 PROBLEMAS COMUNS

## **Problema 1: "Não consigo fazer login no Google"**
**Solução:**
- Use o navegador Chrome ou Safari
- Limpe cookies e cache
- Tente em aba anônima

## **Problema 2: "Não aparece botão Create API key"**
**Solução:**
- Atualize a página (F5)
- Tente em outro navegador
- Verifique se está logado

## **Problema 3: "Perdi a chave do Groq"**
**Solução:**
- Volte em https://console.groq.com/keys
- Clique em "Create API Key" de novo
- Crie uma nova chave

## **Problema 4: "Chave não funciona no app"**
**Solução:**
- Verifique se copiou a chave COMPLETA
- Verifique se não tem espaços no início/fim
- Tente copiar e colar de novo

## **Problema 5: "Não vejo ✓ verde"**
**Solução:**
- A chave precisa ter mais de 10 caracteres
- Verifique se colou no campo certo
- Atualize a página e cole de novo
