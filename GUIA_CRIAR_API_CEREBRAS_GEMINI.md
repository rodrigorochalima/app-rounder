# 1️⃣ CRIAR API KEY DO CEREBRAS

## **PASSO 1: Abrir o link**

👉 **Abra este link no Safari:**
```
https://cloud.cerebras.ai
```

---

## **PASSO 2: Fazer cadastro**

Você vai ver uma tela com 3 opções:

### **OPÇÃO A: Usar Google (MAIS FÁCIL)** ✅

1. Clique no botão **"Google"** (tem o logo do Google)
2. Escolha sua conta Gmail
3. Pronto! Você está dentro!

### **OPÇÃO B: Usar GitHub**

1. Clique no botão **"GitHub"** (tem o logo do GitHub)
2. Faça login no GitHub
3. Pronto!

### **OPÇÃO C: Usar Email**

1. Digite seu email no campo
2. Clique em **"Continue with email"**
3. Verifique seu email
4. Clique no link que chegou
5. Pronto!

---

## **PASSO 3: Acessar Dashboard**

Depois de fazer login, você vai ver o **Dashboard do Cerebras**.

---

## **PASSO 4: Criar API Key**

1. Procure no menu lateral esquerdo por **"API Keys"** ou **"Keys"**
2. Clique em **"Create API Key"** ou **"+ New Key"**
3. Dê um nome: **"App Rounder"**
4. Clique em **"Create"**

---

## **PASSO 5: COPIAR A CHAVE** ⚠️ IMPORTANTE!

1. A chave vai aparecer (começa com `csk-...`)
2. **COPIE AGORA!** Ela só aparece uma vez!
3. Cole em um bloco de notas
4. **NÃO PERCA ESTA CHAVE!**

# 🆘 PROBLEMAS COMUNS

## **Problema 1: Gemini dá erro "API key not valid"**

**Solução:**
1. Aguarde 10 minutos
2. Tente novamente
3. Se não funcionar, crie uma NOVA chave
4. Use o link EXATO: https://aistudio.google.com/app/apikey

---

## **Problema 2: Não acho onde criar API Key no Cerebras**

**Solução:**
1. Depois de fazer login em https://cloud.cerebras.ai
2. Procure no menu lateral: **"API Keys"** ou **"Keys"**
3. Se não achar, clique no seu avatar (canto superior direito)
4. Procure por **"Settings"** ou **"API Keys"**

---

## **Problema 3: Perdi minha API Key**

**Solução:**
1. Volte no site (Cerebras ou Gemini)
2. Crie uma NOVA chave
3. Cole a nova no app
4. **Sempre guarde as chaves em um lugar seguro!**

---

## **Problema 4: Gemini não funciona no Brasil**

**Solução:**
1. Tente usar VPN (mude para EUA)
2. OU use **Cerebras + Groq** (ambos funcionam no Brasil)
3. Vou implementar fallback automático
