## 🚀 Como Usar Diariamente

1. **Acesse**: https://app-rounder.vercel.app
2. **Cole sua API Key do Groq** (só precisa fazer uma vez, salva automaticamente)
3. **Selecione 2 arquivos**:
   - Documento do Round Anterior (.docx)
   - Transcrição de Hoje (.docx, .txt, ou ZIP do WhatsApp)
4. **Clique em "Gerar Round de Hoje"**
5. **Baixe o documento gerado** com o nome `Round DDMMYY.docx`

## 🔧 Funcionalidades Implementadas

✅ **Preserva 100% da formatação** (logo, tabelas, fontes, cores, espaçamento)
✅ **Atualiza data automaticamente** (formato: "DIA DA SEMANA, DD DE MÊS DE YYYY")
✅ **Sistema de cores**:
   - 🔴 **Vermelho**: Itens novos (exames, antibióticos, condutas)
   - 🟡 **Amarelo sublinhado**: Itens pendentes (com contador de dias)
   - 🟢 **Verde**: Itens completados
   - 🔵 **Azul**: Títulos dos leitos

✅ **Contadores automáticos**:
   - Antibióticos: D0 → D1 → D2 → D3...
   - Exames pendentes: incrementa dias
   - Consultas pendentes: incrementa dias

✅ **Suporte a múltiplos formatos**:
   - Documentos Word (.docx)
   - Texto puro (.txt)
   - ZIP do WhatsApp (extrai transcrição automaticamente)

✅ **Histórico**: Últimos 5 documentos gerados

✅ **API Key salva automaticamente** (pergunta só uma vez)
